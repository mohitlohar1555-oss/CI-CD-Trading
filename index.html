1. What is DevOps?

DevOps is a combination of Development and Operations. It is a methodology that helps teams develop, test and deploy software faster through automation and collaboration.

DevOps Goal: Improve software delivery speed, quality, reliability and collaboration.

2. What is Docker?

Docker

Containerization Platform

Docker is an open-source platform used to build, package and run applications inside containers.

Why use Docker?

  • Application portability
  • Lightweight containers
  • Faster deployment
  • Consistent environments
  • Easy application scaling
  • Efficient resource utilization

Docker Architecture

Important Docker components:

  • Docker Client: Sends commands to Docker Engine.
  • Docker Daemon: Manages Docker objects.
  • Docker Image: Blueprint for creating containers.
  • Docker Container: Running instance of an image.
  • Docker Registry: Stores and distributes images.

4. What is a Dockerfile?

A Dockerfile is a text file containing instructions to build a Docker image.

Example Dockerfile

FROM nginx:latest

WORKDIR /usr/share/nginx/html

COPY index.html .

EXPOSE 80

CMD ["nginx", "-g", "daemon off;"]

Build and Run

docker build -t mywebsite .
docker run -d -p 9090:80 mywebsite

5. What is Jenkins?

Jenkins

Automation Server

Jenkins is an open-source automation server used for Continuous Integration and Continuous Delivery (CI/CD).

Advantages of Jenkins

  • Automates software builds.
  • Automates testing.
  • Automates deployments.
  • Supports many plugins.
  • Integrates with GitHub and Docker.
  • Supports CI/CD pipelines.

Jenkins Important Components

  • Controller: Manages jobs and schedules builds.
  • Agent: Executes build tasks.
  • Job: Defines an automation task.
  • Pipeline: Defines the CI/CD workflow.
  • Plugins: Extend Jenkins functionality.

7. Connect Docker with Jenkins

Install Docker on the same EC2 instance where Jenkins runs. 

sudo dnf install docker -y

sudo systemctl enable --now docker

sudo usermod -aG docker jenkins

sudo systemctl restart docker

sudo systemctl restart jenkins

Verify Connection

id jenkins

sudo -u jenkins docker --version

sudo -u jenkins docker ps

sudo docker run hello-world
Important: Jenkins must have permission to access the Docker daemon. Docker group access grants powerful, effectively root-level privileges. Use it only on a trusted Jenkins host.

9. Jenkins CI/CD Pipeline

A CI/CD pipeline automates the process of building, testing and deploying applications.

Example Jenkinsfile

pipeline {
    agent any

    stages {

        stage('Git Checkout') {
            steps {
                git branch: 'main',
                url: 'https://github.com/USERNAME/REPOSITORY.git'
            }
        }

        stage('Docker Version') {
            steps {
                sh 'docker --version'
            }
        }

        stage('Build Image') {
            steps {
                sh 'docker build -t myapp:latest .'
            }
        }

        stage('Run Container') {
            steps {
                sh '''
                docker rm -f myapp || true
                docker run -d \
                --name myapp \
                -p 9090:80 myapp:latest
                '''
            }
        }
    }
}

Open your deployed application:

http://YOUR-EC2-PUBLIC-IP:9090

11. Interview Questions
